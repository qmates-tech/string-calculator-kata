# StringCalculator

Java API backend (embedded Jetty) implementation of the [String Calculator Kata](../README.md).

## Requirements

- Java 21+

## Build and Run

Compile the project:

```bash
./mvnw compile
```

Run the server:

```bash
./mvnw compile exec:java
```

The server starts on `http://localhost:8080`.

## Tests

Run the tests with:

```bash
./mvnw test
```
