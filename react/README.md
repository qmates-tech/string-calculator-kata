# String Calculator - React Component

Typescript React implementation of the [String Calculator Kata](../README.md).

## Requirements

- Node.js `20.10.0`

## Build and run tests

Install dependencies with:

```bash
$ npm install
```

Run the tests with:

```bash
$ npm test
```

## Try it

Serve the demo page with:

```bash
$ npm run dev
```

then visit http://localhost:5173/
